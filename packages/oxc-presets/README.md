[![npm downloads](https://img.shields.io/npm/dm/@aklesky/oxc-presets)](https://www.npmjs.com/package/@aklesky/oxc-presets)
[![license](https://img.shields.io/npm/l/@aklesky/oxc-presets)](https://github.com/aklesky/node-workspace/blob/next/LICENSE.md)

Shareable oxlint and oxfmt presets for TypeScript projects.

The lint and format setup of [@aklesky/eslint-presets](https://www.npmjs.com/package/@aklesky/eslint-presets) and [@aklesky/prettier-presets](https://www.npmjs.com/package/@aklesky/prettier-presets) for the Oxc toolchain, so a project can switch tools without changing its rules or style. Part of the [@aklesky/node-presets](https://github.com/aklesky/node-workspace#readme) collection.

## Features

- **Generated by the official migration tools.** `@oxlint/migrate` and `oxfmt --migrate=prettier` produced both presets from the ESLint and Prettier presets, so the rules and formatting match.
- **Type-only imports stay type-only.** `typescript/consistent-type-imports` and `typescript/no-import-type-side-effects` are on.
- **ES modules only.** `typescript/no-require-imports` is an error everywhere.
- **Prettier-compatible formatting.** oxfmt uses the same options as the Prettier preset and leaves `package.json` key order alone.

## Installation

```bash
pnpm add -D @aklesky/oxc-presets oxlint oxfmt
```

`oxlint` and `oxfmt` are optional peer dependencies, so a project can install only the tool it uses.

## Usage

`oxlint.config.ts`:

```ts
export { default } from '@aklesky/oxc-presets/oxlint.js'
```

To change a rule, extend the preset:

```ts
import preset from '@aklesky/oxc-presets/oxlint.js'
import { defineConfig } from 'oxlint'

export default defineConfig({
    extends: [preset],
    rules: {
        'no-console': 'off'
    }
})
```

For React, use `oxlint-react.js`. It adds the `react` plugin with the React Compiler, hooks and JSX rules from the Vite React template:

```ts
export { default } from '@aklesky/oxc-presets/oxlint-react.js'
```

`oxfmt.config.ts`:

```ts
export { default } from '@aklesky/oxc-presets/oxfmt.js'
```

To change a setting, spread the preset:

```ts
import preset from '@aklesky/oxc-presets/oxfmt.js'
import { defineConfig } from 'oxfmt'

export default defineConfig({
    ...preset,
    printWidth: 100
})
```

Run the tools from your `package.json` scripts:

```json
{
    "scripts": {
        "lint": "oxlint",
        "format": "oxfmt --check"
    }
}
```

oxlint and oxfmt only load a shared preset from a TypeScript config file; `.oxlintrc.json` and `.oxfmtrc.json` cannot import packages.

## Presets

| Import                                 | Contents                                             |
| -------------------------------------- | ---------------------------------------------------- |
| `@aklesky/oxc-presets/oxlint.js`       | the `@aklesky/eslint-presets` rules for oxlint       |
| `@aklesky/oxc-presets/oxlint-react.js` | `oxlint.js` plus the React rules and browser globals |
| `@aklesky/oxc-presets/oxfmt.js`        | the `@aklesky/prettier-presets` options for oxfmt    |
